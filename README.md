# SQL Business Analytics

A portfolio project demonstrating relational database design and business analytics using MySQL.

## Analysis Covered

- Total revenue
- Revenue by product category
- Top products
- Customer contribution
- Premium vs regular customer comparison
- Monthly revenue
- Payment method distribution
- Average order value
- Orders by city
- Reusable SQL view for order-level reporting

## Technology

**MySQL | SQL | Relational Database | Data Analysis**

## Files

| File | Purpose |
|---|---|
| `schema.sql` | Creates database, tables and sample records |
| `analytics_queries.sql` | Business analysis queries |
| `views.sql` | Creates a reusable order summary view |
| `README.md` | Project documentation |

## Concepts Demonstrated

- Database schema design
- Primary and foreign keys
- INNER JOIN
- GROUP BY
- Aggregate functions
- ORDER BY
- Date functions
- Views
- Business metrics
- Revenue analysis

## Run

1. Open MySQL Workbench or phpMyAdmin.
2. Run `schema.sql`.
3. Run `analytics_queries.sql`.
4. Run `views.sql`.

The project uses sample e-commerce-style data for demonstration.

## Portfolio Focus

This project demonstrates practical SQL skills for extracting, transforming and summarizing business data from relational databases.
